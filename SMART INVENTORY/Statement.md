# Project Statement

## Smart Inventory & Stock Analyzer

### Problem Statement

With a growing number of products, it can be hard to manage them manually.
It becomes challenging to keep track of the number of items, their pricing, category, and quantity.

The Smart Inventory & Stock Analyzer is a Python project that is intended to give an easy inventory management system that allows the user to add, remove, search, update, display, sort, and analyze products.

This project was created using basic Python programming concepts, and it can be handled by a 1st-year BTech CSE student.
---

### Objectives

#### The objectives of this project are:

1. Develop a basic inventory management system using Python
2. Store products in form of dictionaries
3. Add and remove products
4. Search and update products

5. Analyze the stock of products

6. Determine the maximum and minimum stock
7. Get the list of low stock products
8. Use sets to store the categories of products
9. Sort products according to their stock
10. Get the K th smallest stock
11. Demonstrate basic Python programming concepts
---
### Features
This project has the following features:

- Add a product
- Remove a product
- Search a product

- Display inventory
- Get the product with maximum stock
- Get the product with minimum stock
